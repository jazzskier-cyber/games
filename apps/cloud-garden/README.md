# 云上花园 · Cloud Garden

一个中文绘本风攀登小游戏。扮演背着花园的旅行兽，走过 21 关云间旅程，让每座花园盛开。项目位于多游戏仓库的 `apps/cloud-garden/`。

## 启动

推荐 Node.js 24，最低支持 Node.js 22.12。在仓库根目录安装并启动：

```sh
npm ci
npm run dev --workspace=cloud-garden
```

打开终端显示的本地地址。以下命令在游戏目录运行，也可以从根目录加上 `--workspace=cloud-garden`：

- `npm run build`：TypeScript 检查和静态生产构建，输出到 dist/。
- `npm run preview`：预览生产构建。
- `npm test`：关卡、物理和完整通关模拟测试。

## 21 关旅程

完整难度顺序：`EEMMEMHEMMEHEMMHEHMEM`。E = 简单，M = 中等，H = 困难。顺序与用户确认一致，第 21 关为中等。

| 难度 | 每关云岛 | 普通平台宽度 | 高度间隔 | 绒球与侧风 |
| --- | --- | --- | --- | --- |
| E 简单 | 10 | 260 | 90 | 后半段开始出现慢速绒球，无风 |
| M 中等 | 12 | 200 | 96 | 更早出现、更快的绒球，无风 |
| H 困难 | 14 | 155 | 102 | 快速绒球，空中有可见的左右侧风 |

除第一关手工教学路线外，其他关卡使用固定种子生成各自路线。每关布局固定、可重玩；所有难度都有无限救回和逐岛花朵检查点。风景按微风草甸、蜂蜜溪谷、暮光花径、晨露云海切换色调；沿用相同绘本素材。

顶部「旅程地图」可以自由选择任意一关。通关后主按钮进入下一关；最后一关返回地图。已通关标记、每关最佳分数、下次出发的关卡保存到本机 localStorage。地图打开时暂停游戏，关闭后可继续；重玩当前关不会降低最佳分数。

## 第一关：风起的地方

- 10 座宽阔浮岛，第一跳原地就能成功。
- 按进度介绍跳跃、移动、阳光收集、叶子挥击和敌人。
- 第 7 座云岛才开始出现缓慢移动的绒球。
- 每座新浮岛都有一朵「记忆小花」。到达时花苞绽放，最新花朵会发光；跌落或碰到绒球时回到这座浮岛，阳光不丢失，不限重试。
- 晶石是可选奖励，破坏晶石不会破坏安全路线。
- 跳跃带离地宽限和提前按键缓冲；手机视野会跟随角色横向移动。
- 到达第 10 座云岛完成第一关；收集阳光并非通关硬性条件。
- 小花的关内位置只在当前游玩中保存；刷新后从已保存关卡的起点出发。

## 操作

左右方向键 / A、D 移动；空格 / W / ↑ 跳跃；J 叶子挥击；P / Esc 暂停。手机使用底部按钮，可同时移动和跳跃。窗口失焦会自动暂停。声音默认关闭，可在右上角开启。

阳光每缕 100 分；晶石 50 分；赶走绒球 100 分；简单、中等、困难通关分别奖励 500、700、1000 分。顶部显示已收集阳光数量，通关时显示总积分。

## 技术与素材

TypeScript + Vite + Phaser 3，中文 HTML/CSS 界面，Web Audio 合成反馈音效。核心模拟位于 src/world.ts，场景和界面位于 src/main.ts。浮岛使用代码生成带细节的纹理；角色和背景使用本地 AI 生成图片。没有游戏运行时 AI API、账号或外部素材请求。

素材及完整生成提示词记录在 [ASSETS.md](ASSETS.md)。绘本背景和旅行兽由内置 ImageGen 生成，保存到 public/assets/。它们同时用于封面及实际游戏；角色动画是图片的呼吸、转向、起落挤压和摇摆，尚不是逐帧骨骼动画。

## 验证与发布

52 项自动测试覆盖准确的 21 关难度顺序、独立路线、小花激活、碰撞、原地第一跳、跌落保留阳光与检查点、可选破岩、全部 21 关在 30fps 和 60fps 下使用正常输入完整通关、通关奖励只发一次、关卡推进与最佳分数存档。构建已验证。当前环境浏览器控制工具无法启动，因此选关弹窗、花朵视觉和手机触摸手感尚需人工试玩。

将 `apps/cloud-garden/dist/` 部署到静态托管服务即可；Vite 使用相对资源路径，支持子目录发布。提交游戏平台前应核对该平台当时的要求。源码推送与在线游戏部署相互独立。
