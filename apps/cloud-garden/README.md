# 云上花园 · Cloud Garden

一个中文绘本风攀登小游戏。扮演背着花园的旅行兽，走过 21 关云间旅程，让每座花园盛开。项目位于多游戏仓库的 `apps/cloud-garden/`。

## 启动

推荐 Node.js 24，最低支持 Node.js 22.12。在仓库根目录安装并启动：

```sh
npm ci
npm run dev --workspace=cloud-garden
```

打开终端显示的本地地址。以下命令在游戏目录运行，也可以从根目录加上 `--workspace=cloud-garden`：

- `npm run build`：TypeScript 检查和静态生产构建，输出到 dist/。
- `npm run preview`：预览生产构建。
- `npm test`：关卡、物理和完整通关模拟测试。

## 21 关旅程

完整难度顺序：`EEMMEMHEMMEHEMMHEHMEM`。E = 简单，M = 中等，H = 困难。顺序与用户确认一致，第 21 关为中等。关卡会轮换核心玩法：弹簧花弹跳、左右漂移云台、限时碎裂云台、高空侧风和流星雨；进入关卡前与地图上都会标出本关机制。

| 难度 | 每关云岛 | 普通平台宽度 | 高度间隔 | 挑战 |
| --- | --- | --- | --- | --- |
| E 简单 | 10 | 260 | 90 | 宽平台、慢速绒球；部分关有慢节奏流星 |
| M 中等 | 12 | 200 | 96 | 更早出现、更快的绒球；部分关有流星 |
| H 困难 | 14 | 155 | 102 | 快速绒球、左右侧风；流星出现更频繁 |

除第一关前两座教学云岛外，每局都会依种子改变云台路线与道具组合，并限制相邻平台距离，确保随机路线仍可跳到。碎云台消失 3 秒后会重新凝成，避免走错后卡在下层。21 关各有独立天空、浮岛与花朵色调。第 6、12、16、19、21 关会下流星石：落下前先给「!」和纵向落点光柱；被砸中会回到最近小花，不会清空进度。前 21 关保留检查点与不限次数救援。

一局从选定关卡开始并沿序通关时，21 关构成 Roguelike 旅程；每局路线与道具组合变化。通关第 21 关后可直接进入无尽云层，持续生成云台、道具、绒球与预警流星；无尽段有 3 次救援机会，耗尽后本局结束。21 关与无尽段共用同一累计总分；“重玩本关”会从当前关起点重开并保留旅程累计分，从地图重新选关则开启新局并清零。通关标记、每关最佳分数和出发关卡保存在本机 localStorage。

## 第一关：风起的地方

- 10 座宽阔浮岛，第一跳原地就能成功。
- 按进度介绍跳跃、移动、阳光收集、叶子挥击和敌人。
- 第 7 座云岛才开始出现缓慢移动的绒球。
- 每座新浮岛都有一朵「记忆小花」。到达时花苞绽放，最新花朵会发光；跌落或碰到绒球时回到这座浮岛，阳光不丢失，不限重试。
- 晶石是可选奖励，破坏晶石不会破坏安全路线。
- 跳跃带离地宽限和提前按键缓冲；手机视野会跟随角色横向移动。
- 到达第 10 座云岛完成第一关；收集阳光并非通关硬性条件。
- 小花的关内位置只在当前游玩中保存；刷新后从已保存关卡的起点出发，并保留本次累计分数。

## 操作

左右方向键 / A、D 移动；空格 / W / ↑ 跳跃；J 叶子挥击；K 使用捡到的道具；P / Esc 暂停。羽毛可在空中再次冲跳，护盾可挡一次撞击，磁石会吸取附近阳光（效果持续 8 秒）。手机使用底部按钮，可同时移动、跳跃和使用道具。窗口失焦会自动暂停。声音默认关闭，可在右上角开启。

阳光每缕 100 分；晶石 50 分；赶走绒球 100 分；简单、中等、困难通关分别奖励 500、700、1000 分。顶部显示已收集阳光数量与旅程累计分数。

## 技术与素材

TypeScript + Vite + Phaser 3，中文 HTML/CSS 界面，Web Audio 合成反馈音效。核心模拟位于 src/world.ts，场景和界面位于 src/main.ts。浮岛使用代码生成带细节的纹理；角色和背景使用本地 AI 生成图片。没有游戏运行时 AI API、账号或外部素材请求。

素材及完整生成提示词记录在 [ASSETS.md](ASSETS.md)。绘本背景和旅行兽由内置 ImageGen 生成，保存到 public/assets/。它们同时用于封面及实际游戏；角色动画是图片的呼吸、转向、起落挤压和摇摆，尚不是逐帧骨骼动画。

## 验证与发布

70 项自动测试覆盖准确的 21 关难度顺序、随机路线在多种种子下可通关、无尽段前 40 座云岛的连续攀登与当前落脚点引导、碎云台重生与软锁保护、无尽救援次数、关卡机制、道具、碰撞、21 关在 30fps 和 60fps 下通关、累计分数与排行榜幂等重试。构建已验证；仍建议真人试玩无尽段难度曲线与手机操作手感。

将 `apps/cloud-garden/dist/` 部署到静态托管服务即可；Vite 使用相对资源路径，支持子目录发布。提交游戏平台前应核对该平台当时的要求。源码推送与在线游戏部署相互独立。
# 1GP 排行榜

游戏仅在 ai-made.games 的嵌入式玩家中启用现有榜单（board `64121e15-e58b-4bc6-8139-4490b1ce5423`）。榜单一局对应从选定关卡开始的连续旅程 session：累计 21 关和无尽段中实际获得的 `Journey.score`，整局结束、无尽救援耗尽或离开页面时提交一个总分。重载后从已保存关卡继续时保留累计积分；重开整段旅程或地图选关会清零。平台榜单负责 Today / This Week / All Time 个人最高分窗口。

集成使用原生 `postMessage` 会话握手和 `fetch` REST API，不读取平台登录 Cookie、不持久化玩家 token，也不引入 SDK。累计分数和未完成结算的幂等请求信息保存在本机；离开页面时使用 keepalive 尝试提交，若网络未完成则下次在 1GP 玩家内用原 runId、最终分数与幂等键重试。单独本地运行可累计并保留分数，但跳过线上排名。

注意：浏览器关闭时无法保证网络请求必然送达，因此先保存本机累计分数与待重试结算；平台内恢复后会补交。自动化测试覆盖累计分数、离开时 keepalive、失败重试与榜单请求；没有向线上榜单写入测试分数。
